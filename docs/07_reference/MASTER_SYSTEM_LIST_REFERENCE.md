# Master System List Reference

## Purpose

This file preserves a categorized system reference list for orientation only. It is reference material, not direct implementation authority.

Canonical authority remains in:

- `docs/02_canon/PROJECT_BRAIN.md`
- `docs/02_canon/SYSTEM_MAP.md`
- `docs/03_systems/`
- `docs/04_contracts/`

## Important Note

The prompt for this bootstrap requested preservation of the original large system list, but no external source list was provided in the repository at bootstrap time. The categorized list below is therefore a cleaned seed list derived only from the systems explicitly named in the project brief and repository structure.

This file must be updated if the original historical system list is later imported into `legacy_reference/`.

Legacy inspiration remains reference-only. No legacy code is to be copied directly, and no legacy concept becomes canon until it is explicitly analyzed against current canon and written into canonical documents.
