# Visionary Ideas

## Purpose

This file is the freeform ideation inbox for concepts that may influence the project in the future but are not currently canonical. Material here may be aspirational, exploratory, contradictory, incomplete, or technically unvalidated.

Nothing in this file is directly implementable authority. A future contributor may use it as inspiration, but implementation work must not treat entries here as approved architecture or feature scope.

Cross-reference:

- Promotion path is defined in `docs/01_candidates/CANON_CANDIDATES.md`.
- Canon entry point is `docs/02_canon/PROJECT_BRAIN.md`.

## What Belongs Here

- Broad product visions not yet evaluated against architecture.
- Experimental ideas for campaign genres, AI use cases, tooling, or player experience.
- Contradictory concepts that need review before harmonization.
- Questions framed as proposals rather than as decisions.
- Imported notes from brainstorming sessions that have not been normalized.

## What Does Not Belong Here

- Approved implementation requirements.
- Locked contracts or schemas.
- Hidden architecture decisions.
- Code tasks presented as if they are already authorized.

## Allowed Status Tags

Each entry should start with one status tag:

- `IDEA`: Raw concept with little or no validation.
- `QUESTION`: Open inquiry that may lead to a candidate.
- `EXPERIMENT`: Proposal that likely requires prototype validation.
- `RISK`: Concern or caution raised from visionary discussion.
- `ARCHIVE`: Retained for historical context, not active consideration.

## Entry Template

Use the following template for new entries:

```md
## [STATUS] Title

Date:
Author:
Related Docs:

Summary:

Why it exists:

Potential value:

Known risks:

What would need to be clarified before candidate review:

Suggested next step:
```

## Operating Notes

- It is acceptable for entries to conflict with each other.
- If an entry starts influencing architecture, move it into `docs/01_candidates/CANON_CANDIDATES.md`.
- If an entry cannot yet be evaluated, keep it here and add clearer questions instead of overstating certainty.
